# **App Name**: CyberTerminal Portfolio

## Core Features:

- Animated Typewriter Effect: Create a custom hook for typewriter animations using `setTimeout` to reveal text character-by-character with a blinking cursor.
- Retro Cybernetic Theme: Implement a green monochrome color scheme with terminal-like visuals, CRT screen effects, and monospace typography.
- Navigation Menu: Build a navigation menu using shadcn `<NavigationMenu>` components, including site title, main navigation links, and a dark/light mode toggle switch using `<Switch>`.
- Interactive Project Cards: Create project cards using shadcn `<Card>` components with cybernetic borders, glow effects, animated project titles on hover, and technology tags using shadcn `<Badge>`.
- Contact Form: Implement a contact form using shadcn form components such as `<Form>`, `<FormField>`, `<FormLabel>`, `<Input>`, and `<Textarea>` with terminal-style styling and an animated submit button.

## Style Guidelines:

- Primary color: Green (#00FF00) for a retro terminal look.
- Background color: Dark grey (#121212) with a hint of green for a subtle glow.
- Accent color: Lime green (#32CD32) for highlights and interactive elements.
- Font: 'Source Code Pro' (monospace) for all text elements to mimic a retro terminal interface.
- Note: currently only Google Fonts are supported.
- Use simple, outlined icons to maintain the retro terminal aesthetic.
- Design a layout with a header, hero section, about section, projects section, contact section, and footer, all styled with the retro cybernetic theme.
- Implement typewriter animations for headings, blinking cursor effects, and subtle screen flickering to enhance the retro feel.
